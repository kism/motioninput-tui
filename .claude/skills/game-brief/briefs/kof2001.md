# The King of Fighters 2001 — brief

A Neo Geo four-button team fighter whose FAQ is written in **pure numpad notation** (`236+P`, `2.8+P`, `2363214+P`) — a dialect `normalise.py` has zero coverage for, so the parser must translate digits to direction tokens before it calls `parse_command`.

- Japan Team: Kyo Kusanagi, Benimaru Nikaido, Goro Daimon, Shingo Yabuki
- Iori Team: Iori Yagami, Vanessa, Seth, Ramon
- Ikari Team: Leona Heidern, Ralf Jones, Clark Steel, Heidern

**Sections to skip:**
- The heading `MAY LEE (HERO)` — an alternate stance-switch moveset for the same slot (entered with `ABC` mid-match). Detect by `(HERO)` in the header line. Its key `may-lee-hero` would otherwise collide with `may-lee-normal` only after you strip the parenthetical; skipping also avoids feeding the engine a stance it cannot model. Cost: ~8 otherwise-simple trainable moves. Keep `MAY LEE (NORMAL)`.
- The `TABLE OF CONTENTS` team list (`- Hero Team   K' / Maxima / Whip / Lin`) — a roster index, not headers.
- Everything from `4. GAMEPLAY NOTES` onward. In particular **Section 5 "STRIKER ACTION LIST"** re-lists every character as `NAME  (Move Name)` with `- ` prose, and **Section 6 "TRANSLATIONS"** has `[ K' ]` sub-rules and `Eins Trigger   First Trigger` lines that read exactly like move lines. The end marker is what protects you here.

**`datagen/names.py` overrides** (keyed by `character_key()` output):
- `may-lee-normal` → `May Lee`
- `leona-heidern` → `Leona` (optional; matches the KoF '98 roster's spelling)
- No ugly-romaji character names in this guide — the move names are romaji but characters are clean. `K'` keys to `k`, `K9999` to `k9999`, both fine.

**Character heading shape:** a name between two `DASHED` rules:
```
 ------------------------------------------------------------------------
 K'  (pronounced "kay dash")                                [ Hero Team ]
 ------------------------------------------------------------------------
```
Rough regex: `^\s*([A-Z][A-Z0-9.'!\- ]{1,40}?)(?:\s+\([^)]*\))?\s{2,}\[\s*([^\]]+?)\s*\]\s*$`. Variant forms: an optional parenthetical between name and bracket (`(pronounced "kay dash")`, `(NORMAL)`, `(HERO)`, `(pronounced "pow")`); boss role strings (`Mid-Boss`, `Last Boss`) in place of a team name.

## Guide anatomy (for the parser)

- **Move-list section:** from the `3. TEAM MOVELISTS` banner (second occurrence — the first is in the table of contents, ~line 40 — banner ~line 313) to `4. GAMEPLAY NOTES` (~line 2650). Take `starts[-1]` for the start and the first hit after it for the end, exactly as `kof98.py._section` does. There is no "alternate characters" section between them; Zero and Igniz are the last two headers before the end marker.
- **Character heading:** as above — name sandwiched between two `DASHED` rules, team in `[…]`, optional parenthetical, subtitle line is not used (unlike KoF '98's Real Orochi Team).
- **Block to parse:** the single command list directly under the header. It ends at the first of `Super Cancels`, `Critical Wire`, `Counter Wire`, `Striker Action`, the `Cancelables` chart, or a line beginning `- `. Note the order is **not fixed** — Mai's `Cancelables` chart precedes her `Super Cancels` block — so stop on any of them. There is no terse/verbose split; this is the only list.
- **Notation dialect:** pure numpad, defined in `2. HOW TO PLAY → FAQ NOTATION` (~line 190): the `7 8 9 / 4 5 6 / 1 2 3` grid, `P Use A or C.`, `K Use B or D.`, `.  charge for 2 sec. in first direction before continuing.`, `~  Indicates middle ranges (so 4~2~6 is 4/1/2/3/6).`, `()x2  perform bracketed commands twice`, `(x#)  perform the listed number of times`. Closest existing parser: **`kof98.py`** — same FAQ author, same `[ Team ]` structure, same `N>4/6+C` throws, same `_` follow-up convention, same Neo Geo panel. Fork it and replace the command-preprocessing.
- **Line-level quirks:**
  - **Command-first line order:** `236+P                  Eins Trigger`. Every existing parser is `Name  command`; here it is `command  Name`. After `split_name_command`, swap the two parts.
  - `Super Cancels` / `Critical Wire` / `Counter Wire` / `Striker Action` lines match the move-line shape (`Label  value`) — add them to `_STOP`. Their continuation lines are indented and land after `_STOP` fires.
  - **Follow-ups** are lines whose command begins `_` (`_6+B`, `_236+P`, `_63214+K`). These are additional inputs off the preceding move. Do **not** strip the `_`: left attached it breaks tokenisation and the move falls out non-trainable, which is correct (matching how `kof98.py` keeps `from X` follow-ups as non-trainable moves). Stripping it would wrongly promote `_6+B` to a trainable "hold forward + B".
  - **Marker prefixes/suffixes** to strip before button substitution: `N>` (near), `F>` (far throw range), `A>` / `<A` (air), `<H` / `H>` (hold), `<T` / `T>` (tap). `A>` should be rewritten to an `In air,` prefix so `_detect_air` fires; the rest can be dropped. Watch that `A>` would otherwise be read as the `A` button (`kof98.py`'s `_BUTTON_LETTER` is `(?<![A-Za-z])([ABCDPK])(?![A-Za-z])`, and `>` is not a letter).
  - Condition prose lines: `From (S)tart:`, `From (M)idst:`, `(see notes)`, `foe attacks_A_8/6/2` (Xiangfei's Esaka). `split_name_command` rejects the first two; the rest normalise to nothing.
  - `CAPS` move names are SDMs (`CHAIN DRIVE`, `URA 108 SHIKI: OROCHI NAGI`); `finish_character` already title-cases them for display. `DM` / `SDM` / `(S)` / `(M)` / `(E)` trailing tags are stripped by `_PARENTHETICAL`.

## Notation & engine fit

- **Buttons A B C D**, panel `NEO_GEO`. From `FAQ NOTATION` (~line 197–198): `P Use A or C.` `K Use B or D.` Same mapping as KoF '98 — A/C punches, B/D kicks.
- **Panel remap:** unchanged from `kof98.py`. `normalise` only emits the Street Fighter six and the recogniser matches `Button` identity, so translate each command to SF notation for `parse_command` (`A`→`LP`, `C`→`HP`, `P`→`any punch`, `B`→`LK`, `D`→`HK`, `K`→`any kick`) and then push the resulting `ButtonRequirement` back onto A B C D with `datagen/parsers/kof98.py`'s `_neo_buttons`. `ALL_BUTTONS` stays the SF six.
- **The new work — numpad translation.** `1`–`9` are not keys in `_SHORTHAND`, `_WORD_DIRECTIONS`, or `_DIRECTION_TOKENS`, so `_direction_tokens` returns `[]` for every KoF 2001 command as written. Per-digit substitution before `parse_command` covers the common cases:

  `6→f 4→b 2→d 8→u 3→df 1→db 9→uf 7→ub 5→n`, joined with commas.

  So `236+P` → `d,df,f + any punch` → `_MOTION_TABLE[("d","df","f")]` = QCF; `623+P` → `f,d,df` = DP; `214+K` → `d,db,b` = QCB; `421+K` → `b,d,db` = RDP; `41236+K` → HCF; `63214+P` → HCB; `236236+P` → QCF_X2; `214214+K` → QCB_X2. Also handle:
  - **`.` charge** (`2.8+P`, `4.6+P`): emit the literal word `charge` plus the two directions so `_resolve_directions` takes the `_CHARGE_TABLE` branch. `2.8` → `charge d,u` → CHARGE_DU; `4.6` → `charge b,f` → CHARGE_BF.
  - **`()x2`** (`(63214)x2+P`, `(41236)x2+K`): expand the bracket contents twice *yourself*. `parse_command` runs `_PARENTHETICAL` first and would delete `(63214)` before `_REPEAT` ever sees it, so left alone these are skipped. Expanded, `(63214)x2` → HCB_X2, `(41236)x2` → HCF_X2 (both trainable).
- **Token collisions:** directions are digits, buttons are the letters `A B C D` (upper), plus the marker letters `N F A T H` and combos `AB CD AC BD ABC ABCD`. A case-sensitive letter swap keeps buttons apart from any lowercased prose, but the marker letters (`N>`, `A>`, `<H`, `T>`) must be consumed first or `A` and `D`… (no direction clash — directions are numeric) will be read as buttons.
- **Compound super motions**, since added to `_MOTION_TABLE`. '98 writes the
  same three as `qcf,hcb` / `qcb,hcf` / `hcb,f`, which now expand to these very
  tuples — a run of shorthands shares the direction its halves meet on:
  - `2363214` → `d,df,f,df,d,db,b` (qcf~hcb) — KoF's standard DM motion: Ryo/Robert/Takuma Ryuuko Ranbu, Iori Ya Otome, King Illusion Dance, Ralf Baribari, Chang Tekkyuu Dai Bousou, Xiangfei Dai Tetsujin, Shingo, Zero… **~16 moves**
  - `2141236` → `d,db,b,db,d,df,f` (qcb~hcf) — Whip Sonic Slaughter, Leona Rebel Spark, Andy Zan'ei Ryuusei, Choi/Kim Hou'ou Kyaku, Lin Ranbu, Athena Shining Crystal Bit… **~13 moves**
  - `632146` → `f,df,d,db,b,f` (hcb,f) — command-grab DMs: Goro Tenchi Gaeshi / Ura Nage, Hinako Kake Nage / Gaburi Yori, Yuri Hyakuretsu Binta, Chang Dai Hakai Nage, Kensou **~9 moves**
- **Still NOT in `_MOTION_TABLE` / `_CHARGE_TABLE`** (skipped after per-digit translation), token sequence and rough cost:
  - `641236` → `f,b,db,d,df,f` — Haou Shoukou Ken (Ryo, Robert, Takuma) **~3**
  - `2362314` → `d,df,f,d,df,db,b` — Seth Irimi-Nadazuki, Kensou Shinryuu, Chin Gou'en Shourai **~4**
  - `21416` → `d,db,b,db,f` — Terry Power Geyser, Kim Hou'ou Kyaku, Andy Chou Reppa (the FAQ's own short form `246+K` → `d,b,f` is also unlisted) **~3**
  - `646` → `f,b,f` — Ryo/Takuma Zanretsu Ken, Robert Gen'ei Kyaku **~3**
  - `16` → `db,f`, `1.6` → `charge db,f`, `2.7~9` → charge d + range — Andy Zan'ei Ken, Takuma/Choi/Mai **~5**

- **Trainable 63%** (`387 / 617`), 57% before the compound motions landed. Below ~80% for three structural reasons, none of them parser bugs:
  - **Normal throws** (~84): every character has `N>4/6+C` and `N>4/6+D`. `4/6` collapses to `b/f` with no separating spaces → no direction token → `normalise` returns "no directional or multi-button requirement". Same outcome as KoF '98.

## Ruleset rationale

At the game-feel layer this game sits **almost exactly where KoF '98 does** — between `SFA3` and `SFIII3`, leaning `SFA3`, with lenient diagonals on. The KoF series buffers motions hard and reads a quarter circle done as `d,f`, but has never had a Capcom-style dragon-punch shortcut. KoF 2001 (the BrezzaSoft/Eolith entry) is widely felt to be a touch *looser and less responsive* than SNK's own KoF games, which argues for slightly wider windows than `kof98`, but I have no frame-data source for 2001 specifically, so treat the deltas below as small and deliberate rather than measured.

- `dp_double_tap = False` — `623+P` means `f,d,df`; hold-down-tap-forward gives nothing. KoF convention.
- `dp_skip_down = False` — `f,df` alone is not a dragon punch here.
- `lenient_diagonals = True` — SNK buffering; `236` done as `d,f` still comes out.
- `charge_ms = 700`, `charge_release_ms = 220` — the FAQ's `.  charge for 2 sec.` is hyperbole; KoF charge moves want ~35–40 frames. A little more forgiving on release than `SFA3`. (Value is an estimate.)
- `negative_edge = True` — the KoF series has had it since the '90s; matches the `kof98` brief.
- `motion_window_ms = 330`, `activation_window_ms = 170`, `step_gap_ms = 190` — interpolated between `SFA3` and `SFIII3`, a hair looser than `kof98` for 2001's sluggish engine.
- `max_intermediate = 1`, `tail_states = 2`, `mash_count = 5` — defaults.
- `rotation_window_ms` / `rotation_slack` — **inert for this game**: there are no `360` / `720` motions in the movelists. KoF 2001's grab supers are `632146` (hcb,f), `41236`, or `(63214)x2`, never full rotations.

**Charge characters:** Leona, Ralf, Clark, Choi, Kim; partial — Takuma (`1.6+K`), Mai (`2.7~9+P`).

**Headline quirk this game teaches:** the notation itself. Every other reference FAQ writes `qcf + P` or spells directions out; this one is pure numpad including `2.8` charges and `2363214` compound supers, so `normalise._MOTION_TABLE` lookups only succeed *after* the parser rewrites digits to direction tokens. Mechanically the game plays like KoF '98; the lesson for the codebase is the parser front-end.

```python
    activation_window_ms=170,

    negative_edge=True,

)
```
